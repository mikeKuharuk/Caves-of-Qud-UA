# Офіційний фреймворк локалізації (гілка `lang-experimental`)

Станом на 2026-09-28. Джерела наведено біля кожного твердження. Позначки:
**[перевірено]** — ми бачили це самі (файли, код, першоджерело); **[за звітом]** — знайдено під час
веб-дослідження, першоджерело не перечитували; **[припущення]** — наш висновок.

  2026-06-30, https://steamcommunity.com/app/333640/discussions/2/563660860618434971/) **[перевірено]**.

## Офіційна документація (вікі)

- https://wiki.cavesofqud.com/wiki/Localization:Overview **[перевірено]**:
  - Текст у Qud процедурний, тож перекладачеві доводиться працювати з шаблонами, а не лише з
    рядками.
  - Івритські запозичення (matz, galgal) треба зберегти.
  - Займенники: they, xe, ey/em (мопанго); у хіндренів є третій гендер — hartind.
  - Мутація Domination переводить опис у друге особу.
  - Переклад — це мод: XML (рядки й шаблони) плюс C# (**replacers**, специфічні для мови).
  - Радять починати зі статичного тексту (`Manual.xml`, `Books.xml`), а динамічний
    (`Strings.xml`) перемежовувати з легшим.
  - Ролі: «перекладач» (XML/JSON) і «програміст» (C#). Розробники можуть допомогти з
    програмуванням.
- https://wiki.cavesofqud.com/wiki/Localization:Setup **[перевірено]**:
  - Перемкнути гру на `lang-experimental` (Властивості → Бета-версії).
  - Увімкнути «Enable mods» і «Allow scripting mods».
  - Мод лежить у `%USERPROFILE%\AppData\LocalLow\Freehold Games\CavesOfQud\Mods`.
  - Потрібні `manifest.json` і `Languages.xml`. Мова обирається пунктом меню в лівому нижньому
    куті титульного екрана, після вибору гра перезапускається.
- https://wiki.cavesofqud.com/wiki/Localization:Strings **[перевірено]**:
  - Кожен файл перекладу має на корені `Lang="uk"` і `Encoding="utf-8"`. Без `Lang` файл
    вантажиться для **всіх** мов, зокрема для англійської.
  - Тип даних визначає корінь: `<strings>`, `<help>`, `<objects>`…
  - В `<string>` атрибут `ID` — **це оригінальний англійський рядок**, `Context` — підказка й
    уточнення. Пошук іде спершу за парою Context+ID, потім лише за ID.
  - Blueprints потребують `Load="Merge"` на **кожному** `<object>`.
  - Плейсхолдери `=num=` зберігати (їх можна переставляти). У шейдерах `{{id|текст}}`
    перекладати лише текст праворуч від `|`.
  - Туторіал поки закінчується на статичному тексті. Динамічний текст «буде описано згодом».

## Формат мод-пакета

`manifest.json` у формі, яку gnarf порадив італійській команді
(https://github.com/sadmozer/caves-of-qud-italian/issues/1) **[за звітом]**:

```json
{
  "ID": "…", "Title": "…", "Description": "…", "Version": "0.0.1", "Author": "…",
  "Tags": "Localization",
  "Directories": [ { "Path": "/Language/", "Version": ">=1.1.0", "Build": ">=2.0.212" } ]
}
```

`Directories` підключає `Language/` лише на збірках ≥ 2.0.212. Семантику `Directories`,
`Version` і `Build` ми бачили в коді 2.0.211 (`XRL/ModDirectory.cs`) **[перевірено]**.

`Languages.xml` (за вікі, Setup) **[перевірено]**:

```xml
<?xml version="1.0" encoding="utf-8"?>
<languages Encoding="utf-8">
  <lang Code="uk" DisplayName="Українська" />
</languages>
```

## Таблиці рядків (ExampleLanguage)

- У грі на `lang-experimental` вони лежать у `CoQ_Data/StreamingAssets/Base/ExampleLanguage/`
  **[за звітом]**.
- gnarf віддзеркалює кожну збірку в https://github.com/gnarf/caves-of-qud-example-language
  (теги `212.4` … `212.31`). Локальна копія — `work/example-language/` **[перевірено]**.
- 40 файлів `*.example.xml`: Strings, Strings.Conversations, Strings.appendix, Books,
  Creatures, Items, Furniture, HiddenObjects, Naming, Skills, Mutations, Quests, Options,
  Manual, PronounSets, Templates та інші. Кожен файл перекладу перейменовується в `*.uk.xml`
  **[перевірено]**.
- Усе, що треба перекладати, позначено префіксом `▶`. Сам префікс нічого не робить, і в
  перекладі його треба прибрати **[перевірено]**.
- Три різновиди записів **[перевірено]**:
  - Таблиці рядків, наприклад
    `<string Context="MainMenu Main" ID="New Game">▶New Game</string>`.
  - Діалоги — теж таблиця рядків, `Context="Conversation <ConvID>.<NodeID>.Text"`, текст
    обрізаний і без відступів.
  - «Злиття» blueprint-ів:
    `<object Name="BaseBear" Load="Merge"><part Name="Render" DisplayName="▶base bear"/>…`.
- У заголовному коментарі кожного файлу перелічено атрибути, які перекладаються
  (`DisplayText`), наприклад `<pronounset … Subjective="DisplayText" …>` **[перевірено]**.

## Відомі пастки фреймворку

Із відгуку Ilya Pirogov (російський переклад на цьому фреймворку, 2026-06-29,
https://steamcommunity.com/app/333640/discussions/2/563660860618434971/) **[перевірено]**:

1. Рядки з характеристиками й механікою, які дописуються до опису під час гри (статистика
   зброї, шанси атаки тощо), — це літерали в C#. Через них покриття впирається в ~80–85%.
2. `=pluralize=`, `=N.things:X=` і `=verb:X=` проходять через англійські `Grammar.Pluralize` /
   `Grammar.ThirdPerson`, і **окремого шва для кожної мови немає**. Ні трьох форм множини, ні
   роду дієслова.
3. Кирилиця **переноситься зарано** й вилазить за межі, бо резервний шрифт `Source Han Mono SC`
   має невдалі метрики. Він вирішив це власним TMP-шрифтом із нормальною моноширинною
   кириличною гарнітурою, а Source Han лишив запасним **[за звітом із пізнішого огляду]**.
4. Шаблони охоплюють ~3 500 із ~5 250 blueprint-ів, і частини UI в шаблонах немає зовсім.
   Пропуски шукають опцією `OptionDebugStringTableMisses` **[за звітом]**.
5. Деякі поля використовують англійське слово як **ключ**: назви слотів (`Bodies.xml
   Type="Head"`), назви кольорів.
6. Частина фраз складається у фіксованому англійському порядку слів.
7. Кореневий елемент — `<lang>`, а не `<language>` (помилка мовчазна). Без `Encoding="utf-8"`
   текст читається як CP437.
8. Хибні `▶`: `ArmsOnEquip BaseHands/Category` і прапорці `xtagGrammar` `massNoun`/`Proper` — це
   ключі. Якщо їх перекласти, гра падає або тихо ламається граматика.

## Що нам дає фреймворк і чого не дає

| Дає | Не дає (доведеться робити самим) |
|---|---|
| Таблиці рядків з ID, вибір мови, UTF-8/UTF-16 | Граматику української: відмінки, рід, 3 форми множини, узгодження прикметників |
| Злиття blueprint-ів, діалоги в таблиці | ~30% тексту, ще не винесеного з коду (до нових збірок — Harmony) |
| Систему replacers з перевизначенням (`Override`) | Нормальний кириличний шрифт для UI (якщо підтвердиться проблема з переносом) |
| Дзеркало ExampleLanguage для відстеження змін | Процедурний текст (HistorySpice, Naming, марковські книги) у структурі для флективної мови |
