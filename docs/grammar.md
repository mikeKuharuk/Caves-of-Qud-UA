# Українська граматика в грі (етап 5)

Гра складає частину тексту в коді з англійською граматикою: дієслова (`=subject.Does:hit=`),
артиклі, займенники, множину (`=turns.things:turn=`). Для таких рядків фреймворк дає дві офіційні
точки **[перевірено в коді]** (`docs/research/framework-212.md`):
- `[LanguageProvider("uk")]` — провайдер мови: артиклі, списки, числа, назви об’єктів;
- `[HasVariableReplacer(Lang = "uk")]` — власні `=змінні=`, які діють лише українською.

Цей документ описує, що мод додає, і синтаксис змінних для перекладачів.

## Що це відкриває

На 2026-09-29 у каталогах лишилося ~12 % слів, яким потрібна граматика:
- **повідомлення з англійською граматикою** (`Strings`, ~6,4 тис. слів);
- **процедурна історія** (`HistoricEvent`, євангелія й агіографії, мурали, ~6 тис.). Їй ще
  потрібен перекладений `HistorySpice.uk.json`: ~14 тис. слів, у статистиці каталогів не видно;
- **процедурні фрагменти** (`xtagTextFragments`, теги сіл, реліквії, рідини, біоми).

Частину таких рядків пакети `Strings-02…07` уже переклали обхідно: двокрапка, безособові
форми, «од.». Вони позначені `qud-ok: placeholder`. З граматикою їх можна переписати природніше.

## Синтаксис для перекладачів

Ключі латиницею, параметри — українські форми. `X` — об’єкт із шаблону (`subject`, `object`
тощо).

| Змінна | Що дає | Приклад |
|---|---|---|
| `=X.v:<3 од.>:<2 мн.>[:<3 мн.>]=` | дієслово теперішнього чи майбутнього часу за особою й числом: гравець → 2 мн., множина → 3 мн. (якщо не дано — 3 од.), решта → 3 од. | `=subject.Name= =subject.v:б’є:б’єте:б’ють= =object.name=` |
| `=X.g:<ч.>:<ж.>:<с.>:<мн.>=` | форма за родом: минулий час, прикметник, дієприкметник. Гравець → мн. | `=subject.Name= =subject.g:упав:упала:упало:упали=.` |
| `=X.Name=` / `=X.name=` | ім’я в називному. Для гравця — «Ви»/«ви» (займенники набору `player`) | |
| `=N.plural:<1>:<2–4>:<5+>=` | слово за числом N (1 хід, 2 ходи, 5 ходів) | `=turns= =turns.plural:хід:ходи:ходів=` |

Правила:
- у перекладі не лишаються англійські `Does`, `verb`, `a/an/the`, `things`, `pluralize`;
- відмінки назв поки що не змінюються. Там, де потрібен непрямий відмінок, будуйте речення
  так, щоб назва стояла в називному (двокрапка, дужки, тире), як і досі;
- `validate` знає ці ключі й перевіряє кількість параметрів.

## Що робить код (`mod/Grammar/`)

- `UkrainianProvider : TranslatorBase` з `[LanguageProvider("uk")]`:
  - артиклі порожні;
  - списки «А, Б і В» / «А, Б або В»;
  - `OrdinalWithDigits` → «30-го»;
  - культура `uk-UA`.
- `UkrainianReplacers` з `[HasVariableReplacer(Lang = "uk")]`: ключі `v`, `g` (для `GameObject`)
  і `plural` (для чисел).
- Рід об’єкта для `g`:
  1. гравець → множина («ви»);
  2. істота з особовим родом гри: male → ч., female → ж., plural → мн.;
  3. інакше — граматичний рід назви з нашого перекладу (`qud-gender`), який збірка кладе в
     дані моду;
  4. якщо його немає — ч.

  Неозайменники й «they» мапляться за рішенням Mike (D11: ey/em → с.; решта чекає відповіді).
- Чиста логіка (вибір форми, множина 1/2–4/5+, рід) — окремі класи без типів гри, щоб їх можна
  було тестувати без Unity.

## Як перевіряється

1. **Компіляція без гри:** `dotnet build` проєкту `tools/grammar-build/`, який посилається на
   бібліотеки гри з `CoQ_Data/Managed` за шаблоном `Mods.csproj.template.txt` (`netstandard2.0`,
   C# 9). Сама гра компілює ці файли з моду.
2. **Тести логіки:** консольний тест-раннер без NuGet (`dotnet run`), лише чисті класи.
3. **У грі** — лише з дозволу Mike (гру без нього не запускаємо):
   - wish `testlangreplacers`;
   - бойові повідомлення;
   - повідомлення від імені гравця.

## Порядок

1. Провайдер + `v`, `g`, `plural`: компіляція й тести.
2. `validate` знає нові ключі; перекладачі отримують цей синтаксис.
3. Переклад граматичних рядків `Strings`; переписати обхідні з пакетів 02–07.
4. Відмінки назв: дані з перекладу (рід, форми) + узгодження прикметників у `DescriptionBuilder`.
5. `HistorySpice.uk.json` і процедурна історія.
6. Перевірка в грі.
