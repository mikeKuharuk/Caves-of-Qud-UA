#### Підсумок
- Основний шлях працює: дані, таблиці рядків і довідка перекладаються самим фреймворком, без
  жодного рядка C#.
- Для граматики є офіційні точки: `[LanguageProvider("uk")]` (артиклі, списки, числа, назви
  об'єктів, перенос рядків) і `[HasVariableReplacer(Lang = "uk")]` (займенники, дієслова, множина
  через наші ключі).
- ⚠️ Шрифти:
  - у пропорційних елементах UI кирилиця береться з іншого, моноширинного шрифту, тож ширини
    не збігаються з латиницею;
  - довгі пункти меню обрізаються;
  - у класичному UI літери дрібні й розріджені.
  Це етап 7.
- ⚠️ Переклад рядка з одним Context може з'явитися в іншому місці з тим самим англійським ID
  (загальна таблиця за ID). Треба пам'ятати, коли однакові англійські слова потребують різних
  перекладів.
- **Не перевірено:**
  - плаваючий текст на карті (у сучасному UI);
  - чи працює `Languages` у `Directories` для C#-коду під час завантаження (до
    `GameManager.Playing` мова = `en`);
  - поведінка на macOS/Linux.
